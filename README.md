# ResumeIQ

ResumeIQ is a modern AI-assisted resume builder and dashboard for creating, editing, previewing, and exporting professional resumes.

The app includes a public landing page, authenticated dashboard, resume customization tools, and a Netlify-ready frontend setup.

## Features

- Create and manage multiple resumes
- Edit resume sections and content in a guided dashboard
- Switch between resume templates and visual styles
- Customize theme colors and typography
- Preview the resume before export
- Clerk authentication for protected user flows
- Supabase-backed resume data storage
- Netlify deployment support with serverless functions

## Tech Stack

- React + Vite
- React Router
- Clerk for authentication
- Supabase for data persistence
- Netlify for hosting and serverless functions
- Tailwind CSS and custom UI utilities
